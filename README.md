# NULHAQFADH — Portfolio

> Personal portfolio website — freelance developer & mahasiswa.

## 🚀 Stack
- HTML5
- CSS3 (custom, no framework)
- Vanilla JavaScript

## 📁 Struktur
```
portfolio/
├── index.html          # Halaman utama
├── css/
│   ├── style.css       # Main stylesheet
│   └── animations.css  # Animasi & efek
├── js/
│   └── main.js         # Script utama
└── assets/
    ├── img/            # Foto & gambar project
    └── icons/          # SVG icons
```

## ✏️ Cara Kustomisasi

1. **Ganti info personal** di `index.html` — nama, email, link sosmed
2. **Tambah skill** di section `skills-grid`
3. **Tambah project** — duplikasi `.project-card` dan isi dengan info projectmu
4. **Ganti warna** — ubah `--green` di `:root` pada `style.css`

## 🌐 Deploy ke GitHub Pages

1. Push ke GitHub
2. Buka **Settings → Pages**
3. Source: **Deploy from branch**
4. Branch: `main` → folder `/ (root)`
5. Save — website aktif dalam beberapa menit!
